# HyperFish — ultra-realistic procedural fish generator

Upgrade of [youssef22karam/fishtest](https://github.com/youssef22karam/fishtest) (IchthyoGen: Three.js r160, React/Vite shell, one big
procedural engine `src/engine/fishgen.js`). Architecture summary and plan: [`docs/UPGRADE_PLAN.md`](docs/UPGRADE_PLAN.md).

```bash
npm install
npm run dev        # or: npm run build  → dist/index.html (single file)
```
Packaging note: in this repo copy, `src/engine/fishgen.js` and `src/engine/hyper/gillchamber.js` are stored as
sequential parts (`src/engine/parts/`, `src/engine/hyper/parts/`) and regenerated by `tools/reassemble.mjs`,
which runs automatically inside `dev`/`build`/`preview`. The generated files are git-ignored; edit the parts.
Some legacy scripts in `tools/` are historical.

## What was added (all global, parameter-driven, seeded — nothing hard-coded per fish)

| file | role |
|---|---|
| `src/engine/hyper/genome.js` | master seed → **sub-seeds** (`sub(seed,'gill')`…): body, head, mouth, eye, gill, oper, each fin, scales, wear, lateral, palette, 12 pattern layers. **9 ecomorph archetypes** (mean + spread vectors, 15 trait axes), soft **blend weights** derived from the engine genome × seeded jitter, constraint rules, coherent palette builder, `validateHyper()` + deterministic **re-roll** of failing seeds |
| `src/engine/hyper/gillchamber.js` | **separate hinged cover pieces** (operculum, suboperculum, interoperculum, preoperculum, branchiostegal membrane with 5–8 rays, soft flap, rear-edge / cheek / brow spines, dermal tassels) · **gill chamber**: dark red cavity, 3–4 arches, two comb rows of crimson filaments per arch (80–250/arch at hero LOD, lamellae striation in the shader), gill rakers (8–40), pseudobranch · hinge + breathing animation (0.5–2 Hz, 5–25°), filament sway |
| `src/engine/hyper/textures.js` | per-part CPU-baked texture sets (albedo+height, normal+roughness+metal), cached: chrome crinkle foil / engraved reticulate (diamond-honeycomb) / rust bumpy / hammered plain; radial striae from the hinge; cracks on old fish |
| `src/engine/hyper/skin.js` | GLSL patches over the engine's body / fin / eye shaders: palette + countershading with soft↔sharp demarcation, **12 independently seeded pattern layers** (speckle, tiger, bars, longitudinal, spots/ocelli, reticulation/vermiculate, mottle (3–5 tones), saddles, head patterns, fin patterns, tail patterns), scale lattice rims/highlights locked to the engine's scale field, lateral line (straight / curved / arch / broken / double) with 40–120 pored scales, myomere chevrons, cephalic sensory pores, eye-region patterns (stripe, bar, rays, ring, brow, post-ocular patch, mottle, vermiculate), rear scutes, wear (scale loss, scars, parasites, algae, bruise) and age tint, iris with 80–200 radial fibres + metallic ring + secondary highlight |
| `src/engine/hyper/rig.js` | studio rig, capture views, turntable, **contact sheet**, automatic **validation**, 10,000-fish instancing **stress test**, the **Hyper** UI panel |

Hooks in `fishgen.js` (search for `HYP`, `hyperFor`): `makeUniforms` / `makeMaterials` wrappers, `buildFish` (head system replaces the painted-on plate for cover plans),
`irisColor`, `FG.hyper`, `installRig`. Small compatibility edits in `headaudit.js`, `anatomycheck.js`, and `checkFishGeometry`. The old plate is still used when
`HYP.on = false`, for LOD2/3 fish and for non-cover plans (sharks/rays keep their own gill slits).

## Using it
* **Hyper** button (bottom bar): gill-cover open slider (1 = 35°, the physiological maximum; values above 1 are a *macro display override* used by the gill close-up),
  breathing toggle, hyper on/off (before/after comparison), wear, bake size (256–2048), **re-roll one subsystem** (proves independence), camera views
  (full / head34 / mouthOpen / gillOpen / eye / scales / fins / belly), *capture all + turntable* (gallery, click to download), **contact sheet (100 seeds)**, **stress 10,000**,
  *validate this fish*, archetype blend readout.
* Console / headless: `FG.hyperRig.shot('gillOpen')` → data-URL, `FG.hyperRig.contactSheet(100)`, `FG.hyperRig.validate(App.fish)`, `FG.hyperRig.findValidSeed('V')`,
  `FG.hyperRig.stress(10000)`, `FG.hyper.hyperFor(genome)` → the full hyper parameter block, `FG.hyper.HYP` (global switches: `on`, `open`, `sub`, `wear`, `texSize`).

## New parameters and ranges (see `genome.js` for the sampler, `HYPER_RANGES` for the enforced ranges)
operculum: height .6–1.05, tip sharpness 0–1, rear curve, edge smooth/wavy/serrated/spined, thickness .5–2 % head length, central spines 0–3, edge/cheek spines 0–10, flap + spot / dark margin,
striae 40–140, crinkle, cracks, open 0–1 (35°), breathing 0.5–2 Hz / 5–25° · gill: arches 3–4, filaments 80–250, rakers 8–40 (4–60 enforced), hue 350–5°, saturation .7–.95, pale 0–.7, pseudobranch 10–22 ·
eye: diameter 12–35 % head, iris fibres 80–200, pupil shape, bulge 0–.3, brow spines 0–6, tentacles 0–3, up to 3 region patterns · head: surface (smooth-scaled / scaled / bony / armored / fleshy), spine length .5–8 % head, tassels 0–20, pores ·
lateral line 40–120 pores · scales: circuli 5–15, overlap .4–.7, film 200–500 nm, roughness .08–.45, clearcoat .6–1 · scutes 0–40 · back value .05–.4, belly value .8–1 · wear 0–1 (default .1–.25; juvenile / adult / old).

## Verification performed (software GL, see `docs/upgrade/`)
* `docs/upgrade/contact_sheet.jpg` — 100 random seeds. The first run correctly flagged a real bug (cover-piece UV skirt overlap, 84 %); fixed, re-run 20/20 pass; the 24-seed engine audit (`checkFishGeometry` + `auditAnatomy`) is 24/24 pass.
* Closeups in `docs/upgrade/a/` (full / head three-quarter / gill open / eye / scales).
* Stress test: 10,000 instanced LOD fish = 12 shared base meshes, 62 draw calls, 17.2 M triangles; build ≈ 37 s in software GL (fps there is meaningless — headless SwiftShader).
* Typical hero fish: 65–115 k triangles (head system 50–85 k); the brief's 200–500 k target is reachable by raising the filament / scale counts.

## Known limitations (honest list)
* Mouth/jaw bones as separate meshes, premaxilla protrusion, and the richer tooth types of Part 5 were **not** rebuilt; the engine's own jaw / lip / teeth system (`mouthgeo.js`, `teethgeo.js`) is used and is only recoloured through the palette.
* Individual scale *geometry* (hero LOD), real fin-ray branching / segmented rays and the geometric scutes are not new: scales are shader relief on the engine's scale field, scutes / lateral line / myomeres / pores are shader features, fin rays are the engine's.
* Eyes: palette-driven iris, fibres, metallic ring, extra highlight — the adipose eyelid and bony brow ring are shader-level; the aphakic crescent is a parameter only.
* Body loft (Part 3: 128–256 stations, 96–192 vertices, superellipse parameters) is the engine's own (96×48 hero).
* LOD0–1 only: the head system is built for `hero` / `med` quality; LOD2/3 use the engine's cover, LOD4 impostors are not implemented.
* The cover-opening angle above 35° is a display override, clearly labelled.
